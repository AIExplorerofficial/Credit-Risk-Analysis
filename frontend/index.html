NOTEBOOK EVALUATION SPLITS

Model metrics

2014 calibration · 2015 read-only OOT

ROC-AUC and PR-AUC assess ranking; Brier score and log loss assess probability accuracy; ECE compares estimated and observed rates; KS measures separation between default and paid-loan scores. For error measures, lower is better. A dash means that value is unavailable for that model/split.

CALIBRATED SCORES · 2015 OOT

ROC curve

This compares how many defaults are caught with how many paid loans are flagged as the score cutoff moves. A curve closer to the top-left generally separates the groups better; the diagonal is a no-skill reference.

CALIBRATED SCORES · 2015 OOT

Precision–recall curve

Precision asks how many flagged loans defaulted; recall asks how many defaults were found. It is useful when defaults are much less common than paid loans.

CALIBRATED PROBABILITIES · 2015 OOT

Calibration curve

The dashed diagonal marks perfect average agreement. Points closer to it mean estimated default chances more closely matched outcomes in that score group.

HOW A RECOMMENDATION IS MADE

Three checks, in order

  1. Check the training range. FICO below 660, debt-to-income above 100%, annual income below $1,000, or requested amount above $40,000 sends the case to Refer because it falls outside the notebook’s support limits.
  2. Check uncertainty near the cutoff. If the conformal model includes both outcomes and the estimated risk is within two percentage points of the 23% threshold, the result is Refer for review.
  3. Apply the saved risk threshold. Below 23% is labelled Approve; 23% or higher is labelled Reject, when neither referral check applies.

These are historical model recommendations, not lending decisions.

SCOPE & LIMITATIONS

What these results mean

  • The website loads the saved preprocessor, LightGBM, Platt calibrator, conformal model, metadata, and processed splits bundled with the authoritative notebook.
  • The target is historical loan default (Charged Off versus Fully Paid). Estimates may not generalize outside that population.
  • 2014 cal_B is used for threshold selection and cohort analysis. The 2015 out-of-time set is read-only evaluation.
  • The notebook’s measured 2015 conformal coverage is 88.95%, below its 90% target. The website displays the observed result without adjustment.
  • The notebook does not calculate an applicant-specific payment. No payment estimate is shown.
  • Historical examples are actual observations from cal_B. What-if comparisons use only the two application records you enter.
